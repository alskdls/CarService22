# Лабораторна робота №2 - ПРОЄКТУВАННЯ, ТЕСТУВАННЯ ТА РЕФАКТОРИНГ СИСТЕМИ УПРАВЛІННЯ АВТОСЕРВІСОМ 

Консольний застосунок управління автосервісом з реалізацією шаруватої архітектури (Model, Repository, Service), калькулятором цін та модульним тестуванням (JUnit 5).

## Структура проєкту
* `org.example.model` — доменні сутності (Order, Car, Client, Job, Mechanic тощо).
* `org.example.repository` — інтерфейс сховища (`RepairOrderRepository`) та його in-memory реалізація.
* `org.example.service` — бізнес-логіка (`CarService`) та калькулятор цін (`PriceCalculator`).
* `src/test/java` — автоматизовані модульні тести.

## Інструкція запуску та тестування

1. **Відкриття проєкту:** клонуйте репозиторій або відкрийте його у середовищі **IntelliJ IDEA**
2. **Запуск демонстрації автосервісу:** перейдіть до файлу `CarServiceDemo.java` (в папці `src/main/java/org/example`) та запустіть його за допомогою зеленої кнопки **Run**
3. **Запуск автоматизованих тестів:**
   * **Через IntelliJ IDEA:** натисніть правою кнопкою миші на папку `src/test/java` у дереві проєкту та виберіть **Run 'All Tests'**
   * **Через термінал (Maven):** виконайте команду `mvn test`
